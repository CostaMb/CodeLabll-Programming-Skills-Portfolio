# Alexa Tell Me a Joke – C++

## Project Description

This is a C++ console application that displays random jokes. Users can choose to hear a joke, view the total number of jokes, or exit the program.

## Features

- Loads jokes from `alexa.txt`.
- Selects jokes randomly.
- Avoids repeating the previous joke when multiple jokes are available.
- Displays the total number of jokes.
- Includes a simple menu and input validation.

## Files

- `alexa.cpp` – contains the C++ source code.
- `alexa.txt` – stores the jokes used by the program.

## How to Compile and Run

Compile the program:

```bash
g++ alexa.cpp -o alexa
```

Run the program:

```bash
./alexa
```

## Testing

I tested the application to confirm that it loads the jokes, displays a random joke, shows the total number of jokes, and exits correctly.
